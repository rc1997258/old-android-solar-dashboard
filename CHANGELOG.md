# Changelog

## Tapo Logger
- **3.1:** keeps working with the screen off or locked: the Live Graph catches up from the log, a 5-minute watchdog restarts logging if Android kills it, and a live status notification.
- **3.0:** Live Power Graph screen with time and date axis, scroll, pinch and − / + zoom, tap-to-read, day navigation, live follow. Faster CSV loading.
- **2.0:** Energy Usage History (Today / 7 / 30 days; Day / Month / Year charts from the plug's memory, offline cache); Tapo-style look.
- **1.0:** KLAP v2 client, background CSV logging, live screen, hashed-login settings, start on boot.

## Soyosource patcher
- One-column layout, solid single-colour values, row height and spacing options.
- 2× stretch with scrolling on every window.
- AP-only boot (v3: delayed switch, so E4A's main window can't cover the dashboard).
- Font scaling in the E4A runtime.
